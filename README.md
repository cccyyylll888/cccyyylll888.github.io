## 仓库内容

```
.
├── _config.yml      # 站点配置（标题、导航、社交链接、配色）
├── index.md         # 首页：自我介绍 + 教育背景 + 项目 + 获奖
├── aboutme.md       # 「关于我」页面
├── _posts/          # 博客文章（暂空）
├── _layouts/        # 模板布局
├── _includes/       # 模板局部组件
└── assets/          # 图片、CSS、JS 静态资源
```

## 本地预览

如果你想 clone 下来在本地预览（需要 Ruby 环境）：

```bash
git clone https://github.com/cccyyylll888/cccyyylll888.github.io.git
cd cccyyylll888.github.io
bundle install
bundle exec jekyll serve
# 浏览器打开 http://localhost:4000
```

更省事的方式是直接推到 GitHub，由 GitHub Pages 自动构建部署。
